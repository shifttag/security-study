EIGRP =====
R1 -----
enable
conf t
router eigrp 100
 no auto-summary
 network 1.1.1.1 0.0.0.0
 network 12.1.1.1 0.0.0.0
R2 -----
enable
conf t
router eigrp 100
 no auto-summary
 redistribute static
 network 12.1.1.2 0.0.0.0
 network 23.1.1.2 0.0.0.0
R3 -----
enable
conf t
router eigrp 100
 no auto-summary
 network 2.2.2.1 0.0.0.0
 network 23.1.1.3 0.0.0.0
